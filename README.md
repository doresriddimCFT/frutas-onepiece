# Frutas del Diablo - One Piece

(Es una página web que consulta la API de One Piece, muestra las Frutas del Diablo como tarjetas con Bootstrap y las filtra por nombre a medida que escribes en el buscador).

## Tecnologías
(HTML, JavaScript, Bootstrap 5.3.3 por CDN; no usa CSS propio)

## Funcionamiento
(Consume la API, muestra tarjetas, filtra por nombre mientras escribes)

## API utilizada
("https://api.api-onepiece.com/v2/fruits/en")

## Cómo ejecutarlo
(Abrir index.html en el navegador)
